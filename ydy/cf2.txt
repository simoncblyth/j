My first step to debugging hit number differences will be 
to use common input photons that target specific PMTs.  
This can be done by replacing "gun" with "opticks" on the 
tut_detsim.py commanline and setting some envvars to 
configure the frame of the input photons and which input photons to use:: 

   export SEvt__INPUT_PHOTON_DIR=/cvmfs/opticks.ihep.ac.cn/.opticks/InputPhotons
   export OPTICKS_INPUT_PHOTON=RainXZ_Z230_10k_f8.npy 
   export OPTICKS_INPUT_PHOTON_FRAME=NNVT:0:1000  

If studies using common photons fed to G4 and OK do not
reveal the problem then I will revive random aligned 
running where I control the random numbers consumed by 
the two simulations in addition to the input photons. 
That allows direct step-by-step matching 
between the simulations unclouded by statistics.
