propagation from Geant4 saving into SEvt that are persisted
into the B000 B001 folders of .npy that look like

> I am trying to compare hit.npy and seq.npy between G4 and Opticks,

You need to use --opticks-anamgr that switches on U4RecorderAnaMgr 
which collects full Geant4 optical propagation info into Opticks
SEvt which get saved to B000 B001 folders.

Alternatively when using Opticks at C++ level without the python
(and without the above LSExpDetectorConstruction_Opticks::Setup)
the envvar OPTICKS_INTEGRATION_MODE is used to do the 
same thing as the python --opticks-mode option. 
The envvar initializes SEventConfig::IntegrationMode() 


> I tried opticksMode 3, and I need to switch off all anamgrs to make it works.
> It means no data saved to root files.  And JUNOSW use root file to save SimEvt
> data, and Opticks use some npy files.  I want to know if Opticks use npy files
> to "replace" the root file, or the root file still makes sense.

The opticksMode:3 and saving of .npy are only for debugging/validation, 
they do not replace the root files.
 
The .npy give far more info than the root files. Every step (up to 32) 
of every photon can be recorded into the record.npy making them 
far too big for ordinary usage. As you discovered by writing almost
a terabyte of them.
