VR SLI
--------

* https://developer.nvidia.com/vrworks/graphics/vrsli

Sharing VR rendering work across 2 or more GPUs


VR SLI for OpenGL is accessed through a new OpenGL extension called
“GL_NVX_linked_gpu_multicast” that can be used to greatly improve the speed of
HMD rendering. With this extension, it is possible to control multiple GPUs
that are in an NVIDIA SLI group with a single OpenGL context to reduce overhead
and improve frame rates. .

* https://developer.nvidia.com/blog/vr-sli-accelerating-opengl-virtual-reality-multi-gpu-rendering/
